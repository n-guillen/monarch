# Monarch
Monarch is a dynamic analysis tool intended to be used for modding games and applications under personal use.

## Work In Progress
This software is currently a work in progress, and is still heavily under-developed. Here are the goals that Monarch has set to achieve:
- Organized file structure, scalable codebase.
- Efficient analysis algorithms (scanning memory). 
- Cross-platform support.
- Basic alternative to [Cheat Engine.](https://github.com/cheat-engine/cheat-engine/)
- GUI (interested in [GTK](https://www.gtk.org/)).
